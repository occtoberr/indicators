# Indicators

A customizable Minecraft HUD mod for Fabric.

Indicators displays important player information directly on your screen, including health, ping, and FPS. It is designed to be lightweight, simple, and customizable.

## Features

- **Health Indicator:** Displays your current health.
- **Ping Indicator:** Displays your connection latency in milliseconds.
- **FPS Indicator:** Displays your current frames per second.
- **Customizable Positions:** Choose where each indicator appears on your screen.
- **Custom Colors:** Customize the color of each indicator.
- **Independent Toggles:** Enable or disable indicators individually.
- **Optional Labels:** Choose whether to display labels alongside indicator values.
- **Configuration:** Customize your HUD through the Mod Menu configuration screen.

## Compatibility

| Requirement | Version |
|---|---|
| Minecraft | 26.2 |
| Mod Loader | Fabric |
| Java | 25 or newer |
| Fabric API | Required |

Mod Menu is required for accessing the in-game configuration screen.

## Installation

1. Install Fabric Loader for Minecraft 26.2.
2. Install Fabric API.
3. Download the latest Indicators release.
4. Place the downloaded JAR file into your Minecraft `mods` folder.
5. Launch Minecraft.

## Development

Indicators is developed using Java and the Fabric modding API.

This project was primarily vibe-coded with **OpenAI ChatGPT GPT-6**, with AI assistance used for code generation, debugging, implementation, and development guidance.

The project is still under development, and features may change over time.
